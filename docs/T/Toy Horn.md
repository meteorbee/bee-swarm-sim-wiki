# Toy Horn

{{Unobtainable}}
{{Beequip}}
A '''Toy Horn''' is a [[Bond|level]] 9 [[:Category:Beesmas|Beesmas]] [[Beequip]]. It has an equip limit of two. There is no color requirement. It can only be equipped to [[Brave Bee|Brave]], [[Rage Bee|Rage]], [[Lion Bee|Lion]], [[Cobalt Bee|Cobalt]], or [[Crimson Bee|Crimson]] [[bees]].
