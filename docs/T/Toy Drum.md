# Toy Drum

{{Unobtainable}}
{{Beequip}}
A {{Color|Toy Drum}} is a [[Bond|level]] 7 [[:Category:Beesmas|Beesmas]] [[Beequip]]. It has an equip limit of two. It has no color requirement. It can only be equipped to [[Brave Bee|Brave]], [[Demo Bee|Demo]], [[Bucko Bee|Bucko]], or [[Riley Bee|Riley]] [[bees]].
