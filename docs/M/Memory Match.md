# Memory Match

'''Memory Match''' is a match-style minigame located in various places throughout the map. The goal is to match as many pairs as possible to win [[items]]. There are four (five during Beesmas) of these machines that can be used. Each machine costs a varying amount of [[honey]] (See "[[Memory Match#Machines|Machines]]").
__NOTOC__
== Gameplay ==
[[File:MemoryMatchScreen.png|thumb|The Night Memory Match Screen. An example of a board of size 4x4 cards.]]
[[File:Ossas.png|thumb|The Extreme Memory Match screen. An example of a board of size 4x5 cards.]]
When activated, a screen will pop up with a board of size 4x4 or 4x5 cards. A player has a limited number of chances to match cards together. Matching a pair also costs a chance. They can gain more chances if they have the required [[Badges|badge]] and its rank to get it. 

Machines with rarer rewards require more honey and a higher badge rank for extra chances. They also have a longer cooldown between each activation.

If at least one match is made, a message will appear in the chat: {{Notification|Honey|Winner!}}, with the items received listed below.

If no matches are made, a message will appear in the chat: {{Notification|2=Better luck next time!}}

== Machines ==

== Trivia ==
* The Extreme Memory Match is the biggest Memory Match machine in terms of the "computer" model size. It is also the most expensive machine in terms of honey.
* If the player started a new memory match game while one was already active, the new game would not have started, but the player still had to pay the fee and wait for the cooldown. This is no longer possible because the player's movespeed is set to zero during a memory match game.
** The player can still move during the minigame by using the [[Parachute]] or [[Glider]].
* The Winter Memory Match is the only machine that can only be accessed during an event and requires the completion of a quest to use, namely [[Spirit Bear#Beesmas Quests|Spirit Bear's quest for that Beesmas]].
* The Winter Memory Match had an unusual bug. When the player did not have enough snowflakes, trying to use the machine displayed the message: {{Notification|Red|and Complete 1 Quest to You need 100 Snowflakes to play Winter Memory Match.}} <!-- when was this bug around? -->
<!-- are we sure this trivia should exist? it assumes no duplicate pairs, and honestly i can't be bother to fact-check this -->
* Assuming there are no duplicate pairs and the player is playing optimally, the chances of getting any prizes in a Memory Match for each board size is:
** For 4x4: about 37% for 3 chances, 46% for 4 chances, 54% for 5 chances, and 60% for 6 chances. 
** For 4x5: about 45% chance to reward the player if they receive 5 chances, 51% for 6 chances, 56% for 7 chances, and 61% for 8 chances.
