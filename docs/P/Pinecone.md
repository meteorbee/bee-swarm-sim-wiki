# Pinecone

{{Unobtainable}}
{{Beequip}}
A {{Color|Pinecone}} is a [[Bond|level]] 9 [[:Category:Beesmas|Beesmas]] [[Beequip]]. It has an equip limit of two. There is no color requirement. It can only be equipped to [[Bumble Bee|Bumble]], [[Stubborn Bee|Stubborn]], [[Bucko Bee|Bucko]], [[Frosty Bee|Frosty]], [[Carpenter Bee|Carpenter]], or [[Bear Bee|Bear]] [[bees]].
