# Paper Angel

{{Unobtainable}}
{{Beequip}}
A {{Color|Paper Angel}} is a [[Bond|level]] 8 [[:Category:Beesmas|Beesmas]] [[Beequip]]. It has an equip limit of two. There is no color requirement. It can only be equipped to [[Bomber Bee|Bomber]], [[Rascal Bee|Rascal]], [[Shy Bee|Shy]], or [[Photon Bee|Photon]] [[bees]].
