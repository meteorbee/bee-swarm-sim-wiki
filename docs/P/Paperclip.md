# Paperclip

{{Beequip}}
A {{Color|Paperclip}} is a [[Bond|level]] 7 [[Beequip]]. It has an equip limit of two. There is no color requirement. It can only be equipped to [[Bees/Rare|rare]] or [[Bees/Epic|epic]] [[bees]].

*As a very rare drop from the {{Cost|Petal Planter|4=0}}.

*As a drop from the {{Cost|Blue Clay Planter|4=0}}.
