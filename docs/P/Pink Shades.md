# Pink Shades

{{Beequip}}
{{Color|Pink Shades}} are a [[Bond|level]] 10 [[Beequip]]. It has an equip limit of one. There is no color requirement. It can only be equipped to [[Basic Bee|Basic]], [[Rad Bee|Rad]], [[Bomber Bee|Bomber]], [[Demo Bee|Demo]], [[Honey Bee|Honey]], and [[Shy Bee|Shy]] [[bees]], but they must be [[Gifted Bee|gifted]].
