}}The '''[[w:c:Roblox:Winter Spotlight|{{PAGENAME}}]]''' is a Roblox event that spanned across multiple games. In each game, players had to earn badges, named "Standard Tokens" and "Elite Tokens", to contribute to overarching prizes in the main event hub.
==Overview==
*Completing [[Bee Bear]]'s first three quests awards a [[Badges#Inactive Badges|Standard Token]].
*Opening the [[Gift Boxes#2024 (Winter)|Elite Gift Box]] awards an [[Badges#Inactive Badges|Elite Token]].
