# Warm Scarf

{{Unobtainable}}
{{Beequip}}
The {{Color|Warm Scarf}} is a [[Bond|level]] 5 [[:Category:Beesmas|Beesmas]] [[Beequip]]. It has an equip limit of three. There is no color requirement. It can only be equipped to [[Basic Bee|Basic]], [[Rad Bee|Rad]], [[Exhausted Bee|Exhausted]], [[Frosty Bee|Frosty]], and [[Shy Bee|Shy]] [[bees]].
