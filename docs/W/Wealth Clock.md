# Wealth Clock

[[File:Wealth Clock.png|thumb|205x205px|The Wealth Clock.]]
The '''Wealth Clock''' is a [[:Category:Machines|machine]] that boosts [[System Page#Honey Per Pollen|Honey Per Pollen]] and grants [[ticket]]s to the player. The Wealth Clock is located next to [[Brown Bear]], the entrance to [[Commando Chick's Hideout]] and the [[Honeystorm|Honeystorm Summoner]].

To use the clock, the player will need to have discovered 5 types of [[bees]]. The clock can only be used every hour of playtime. Each use grants x1.01 Honey Per Pollen, which stacks up to 5 times, with a maximum of x1.05 Honey Per Pollen. The Wealth Clock is also able to award {{Cost|Ticket}}, starting at 1 for the first use, increasing the amount of tickets awarded by 1 for every subsequent use until capping at {{Cost|Ticket|5}}, on which the Wealth Clock will only produce {{Cost|Ticket|5}} per use. Every subsequent use will award the player {{Cost|Ticket|5}}. Every time it does, it will say the following:

== Notes ==
* There is a 15-minute grace period (can be offline for 15 minutes) until the Wealth Clock buff resets. This means the player can exit and rejoin, while still maintaining the boost, as long as they join within the 15-minute grace period.
** However, if the player joins in that period of time, the Wealth Clock cooldown will reset back to an hour. 
*** This can be evaded by abusing a bug. If you enter the hive hub and leave the game, the wealth clock will not reset.
* The player can obtain wealth clock boost by redeeming certain [[codes]]:
** There are currently no available codes that grant the wealth clock boost.

== Trivia ==
* The Wealth Clock is located where the Honeystorm Summoner used to be.
* As of the [[Updates#2018.11.25|11/25/2018 update]], it increases the number of tickets it prints each interval. It will also start printing tickets the moment the player starts using it, but the player has to be in the server for 1 hour to use it instead of the previous 30 minute cooldown.
* The amount of tickets granted by the Wealth Clock is based on the player's current stack of the Wealth Clock buff rather than how many times the player has used it (e.g if the player has 1 stack of the Wealth Clock buff and then uses the Wealth Clock for the first time, it will grant 2 tickets instead of 1).
* The [[Badges#Playtime Badge|Playtime Badge]] is represented by the Wealth Clock.
* The Wealth Clock has a 1/250 (0.4%) chance to spawn an {{Cost|Hourglass Sticker|||0}} in the [[Clover Field]].
