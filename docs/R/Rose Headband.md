# Rose Headband

{{Beequip}}
The {{Color|Rose Headband}} is a [[Bond|level]] 13 [[Beequip]]. It has an equip limit of one. There is no color requirement. It can only be equipped to [[Basic Bee|Basic]], [[Rascal Bee|Rascal]], [[Riley Bee|Riley]], [[Diamond Bee|Diamond]], [[Windy Bee|Windy]] and [[Vicious Bee|Vicious]] [[bees]].
