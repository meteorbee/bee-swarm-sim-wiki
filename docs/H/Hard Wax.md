# Hard Wax

{{Consumables
|image=Hardwax.png
|description=A firm hunk of beeswax. Has a 60% chance to improve a bee's Beequip.}}
{{Color|Hard Wax}} is an [[:Category:Inventory|inventory item]] and a type of [[Waxes|wax]] added in the [[Updates#2021.12.26|12/26/2021 update]] that can be used on a [[Beequip]] to improve its stats. Upon usage, it has a 60% chance of improving the Beequip's stats. The other 40% and the Hard Wax gives no improvement, simply taking up a space in a wax slot. Hard Wax has [[Beequip#Stats, Waxes, Chances|Upgrade Value]] of 2.

Hard Waxes can also be used to craft [[tools]] and [[items]], such as [[planter]]s.

If giving a Hard Wax to a [[Bees|bee's]] Beequip is successful, the message pops up saying:

{{Notification|2=The Wax has Improved the Beequip!}}

However, if it fails, the message pops up saying:

{{Notification|Red|The Wax didn't seem to help...}}
