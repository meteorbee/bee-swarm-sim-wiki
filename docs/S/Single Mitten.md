# Single Mitten

{{Unobtainable}}
{{Beequip}}
A {{Color|Single Mitten}} is a [[Bond|level]] 6 [[:Category:Beesmas|Beesmas]] [[Beequip]]. It has an equip limit of three. There is no color requirement. It can only be equipped to [[Bees/Rare|rare]], [[Bees/Epic|epic]], or [[Bees/Legendary|legendary]] [[bees]].
