# Sticker Printer

{{Inaccurate}}
[[File:StickerPrinter.png|The Sticker Printer.|alt=The Sticker Printer.|thumb]]
The '''Sticker Printer''' is a machine past the [[Lion Bee Gate]]. It is located to the right of the Instant Converter next to the [[Mountain Top Field]]. The Sticker Printer costs [[egg]]s (excluding Bee Specific Eggs) to print [[stickers]].

==Mechanics==
The printer can print stickers depending on the type of egg donated, and the quality of the type of stickers from the printer is also affected by the type of the egg inserted. The types of [[Sticker#Sticker Index (being finished 1/13/24-1/14/24)|Hive Skin]], [[Sticker|Cub Skin]] or [[Sticker]] chances can be checked when clicking on an egg before using it to print a sticker. 

The Printer will print one sticker upon use and has a cooldown of 1 hour before it can be used again.<gallery>
