# Snow Tiara

{{Unobtainable}}
{{Beequip}}
A {{Color|Snow Tiara}} is a [[Bond|level]] 12 [[:Category:Beesmas|Beesmas]] [[Beequip]]. It has an equip limit of one. There is no color requirement. It can only be equipped to [[Cool Bee|Cool]], [[Stubborn Bee|Stubborn]], [[Shocked Bee|Shocked]], [[Frosty Bee|Frosty]], [[Diamond Bee|Diamond]], and [[Windy Bee|Windy]] [[bees]]. The bee must be [[Gifted Bee|gifted]] for it to be equipped.
