# Snowglobe

{{Unobtainable}}
{{Beequip}}
A {{Color|Snowglobe}} is a [[Bond|level]] 7 [[:Category:Beesmas|Beesmas]] [[Beequip]]. It has an equip limit of two. There is no color requirement. It can only be equipped to [[Basic Bee|Basic]], [[Bumble Bee|Bumble]], [[Cool Bee|Cool]], [[Bucko Bee|Bucko]], [[Frosty Bee|Frosty]], or [[Windy Bee|Windy]] [[bees]].
