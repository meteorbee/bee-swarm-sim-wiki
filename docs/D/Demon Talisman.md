# Demon Talisman

{{Beequip}}
The {{Color|Demon Talisman}} is a [[Bond|level]] 13 [[Beequip]]. It has an equip limit of one. There is a red color requirement. It can only be equipped to a [[Mutation|mutated]] [[Demon Bee]].
