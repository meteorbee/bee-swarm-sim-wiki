# Debug Wax

{{Unobtainable}}
{{Consumables
|image=Debug Wax.png
|description=100% chance to greatly improve a Beequip.}}{{Color|Debug Wax}} is an [[:Category:Inventory|inventory item]] and a type of [[Waxes|wax]] added in the [[Updates#2024.07.17|7/17/2024]] update that can be used on a [[Beequip]] to boost its stats. Upon usage, it has a 100% chance of greatly improving the Beequip's stats. Debug Wax has an [[Beequip#Stats, Waxes, Chances|Upgrade Value]] of 4.

When applying Debug Wax to a bee's Beequip, a message pops up saying:<br>
{{Notification||The Wax improved the Beequip!}}
==Ways to Obtain==
There are currently no ways to obtain a {{Cost|Debug Wax|||0}}.

=== The methods below are no longer possible. ===
*As a reward for completing [[Bubble Bee Man]]'s quest "B.B.M's Naughty List" during the Winter Beesmas 2024 event.
*As a reward for completing Bubble Bee Man's quest "B.B.M's Naughty List" during the Summer Beesmas 2024 event.

==Trivia==
*This is the only wax which is unable to be crafted.
*This item functions almost the same as a {{Cost|Caustic Wax|||0}}, the only difference being that it always succeeds.
**This item originally shared its icon with Caustic Wax before the [[Updates|12/25/24]] update.
*This item originated from the [[Onett's Testing Group|Test Realm]], being a risk-free way to upgrade Beequips, before officially being added to the game.
*This wax, {{Cost|Soft Wax|||0}}, and {{Cost|Swirled Wax|||0}} are the only waxes guaranteed to change a beequip's stats.
