# Autumn Sunhat

{{Beequip}}
The {{Color|Autumn Sunhat}} is a [[Bond|level]] 16 [[Beequip]]. It has an equip limit of one. There is no color requirement. It can only be equipped to [[Hasty Bee|Hasty]], [[Bumble Bee|Bumble]], [[Looker Bee|Looker]], [[Exhausted Bee|Exhausted]], [[Diamond Bee|Diamond]] and [[Puppy Bee|Puppy]] [[Bees]].
