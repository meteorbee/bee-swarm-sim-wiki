# Nectar Tester

{{Consumables|image=Basic Egg.png|description=This test item grant 24 hours of all Nectars.|cooldown=1h|cap=}}{{Unobtainable}}

The {{Color|Nectar Tester}} is a special item that acts like [[Nectar Vial|nectar vials]], but instead of providing a single [[nectar]] for 4 hours, it provides every type of nectar for 24 hours. It was meant to be only available on Test Realm, but was added to the main game during 2024 Summer Beesmas as a reward for completing [[Bubble Bee Man]]'s Naughty List.
==Ways to Obtain==
There are currently no way to obtain {{Cost|Nectar Tester}}

=== The methods below are no longer possible. ===

* As a reward for completing [[Bubble Bee Man]]'s quest "B.B.M's Naughty List" during the Winter Beesmas 2024 event

* As a reward for completing Bubble Bee Man's quest "B.B.M's Naughty List" during the Summer Beesmas 2024 event.
