# 7-Pronged Cog

{{Unobtainable}}''<sup>Not to be confused with [[Cog]].</sup>''
{{Consumables|image=7 cog.png|description=A component used in mysterious electronics. |cooldown=N/A
}}
{{Color|7-Pronged Cog}} is a special [[:Category:Inventory|inventory item]] added in the [[Updates|11/23/2020 update]] for the [[Ready Player Two]] event. It was used as one of the two ingredients to craft the [[Strange Goggles]].

To obtain the {{Cost|7-Pronged Cog||4=}}, the player would need to redeem seven [[codes]], discovered by various riddles scattered across the map.
