# Beesmas Top

{{Unobtainable}}
{{Beequip}}
A {{Color|Beesmas Top}} is a [[Bond|level]] 4 [[:Category:Beesmas|Beesmas]] [[Beequip]]. It has an equip limit of three. There is no color requirement. It can only be equipped to [[Bees/Common|common]] or [[Bees/Rare|rare]] [[bees]].
