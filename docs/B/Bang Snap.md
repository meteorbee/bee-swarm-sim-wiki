# Bang Snap

{{Beequip}}
The {{Color|Bang Snap}} is a [[Bond|level]] 10 [[Beequip]]. It has an equip limit of one. There is no color requirement. It can only be equipped to [[Bees/Common|common]], [[Bees/Rare|rare]], or [[Bees/Epic|epic]] [[bees]].
