# Bottle Cap

{{Beequip}}
The {{Color|Bottle Cap}} is a [[Bond|level]] 4 [[Beequip]]. It has an equip limit of two. There is no color requirement. It can only be equipped to [[Bees/Common|common]] or [[Bees/Rare|rare]] [[bees]]. It was released in the [[Updates|04/01/2022 update]].
