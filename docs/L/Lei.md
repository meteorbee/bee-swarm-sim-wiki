# Lei

{{Beequip}}
A {{Color|Lei}} is a [[Bond|level]] 14 [[Beequip]]. It has an equip limit of one. There is no color requirement. It can only be equipped to [[Basic Bee|Basic]], [[Looker Bee|Looker]], [[Stubborn Bee|Stubborn]], [[Hasty Bee|Hasty]], and [[Exhausted Bee|Exhausted]] [[Bees]].
