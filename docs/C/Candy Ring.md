# Candy Ring

{{Beequip}}
The {{Color|Candy Ring}} is a [[Bond|level]] 14 [[Beequip]]. It has an equip limit of one. There is no color requirement. It can only be equipped to [[Stubborn Bee|Stubborn]], [[Bumble Bee|Bumble]], [[Honey Bee|Honey]], [[Diamond Bee|Diamond]], [[Festive Bee|Festive]] and [[Gummy Bee|Gummy]] [[bees]].
