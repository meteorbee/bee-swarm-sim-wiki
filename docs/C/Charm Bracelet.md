# Charm Bracelet

{{Beequip}}
The {{Color|Charm Bracelet}} is a [[Bond|level]] 12 [[Beequip]]. It has an equip limit of one. There is no color requirement. It can only be equipped to [[Bees/Legendary|legendary]] [[bees]].
