# Camo Bandana

{{Beequip}}
A {{Color|Camo Bandana}} is a [[Bond|level]] 8 [[Beequip]]. It has an equip limit of three. There is no color requirement. It can only be equipped to [[bees]] with a "[[Ability Tokens#Bomb|Bomb]]" ability.
