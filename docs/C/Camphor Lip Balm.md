# Camphor Lip Balm

{{Beequip}}
The {{Color|Camphor Lip Balm}} is a [[Bond|level]] 12 [[Beequip]]. It has an equip limit of one. There is no color requirement. It can only be equipped to [[Cool Bee|Cool]], [[Stubborn Bee|Stubborn]], [[Commander Bee|Commander]], [[Bubble Bee|Bubble]] and [[Crimson Bee|Crimson]] bees.
